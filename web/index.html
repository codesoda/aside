Simple by design

One command.
A better review.

Aside runs locally, uses the GitHub CLI you already trust and serves its browser interface straight from a Rust executable.

1
Open a pull request.

Pass a GitHub PR URL to aside. It fetches the diff and existing review conversations.

2
Choose your scope.

Ignore noise in the pre-review tree. See unchanged review progress and suggestions for where to look.

3
Review with context.

Read diffs, draft privately, work with an agent, and publish only when you explicitly choose to.
